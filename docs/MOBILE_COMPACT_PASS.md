# Pirate Deck mobile compact pass

Goal: keep the interactive battle (HUD, boss, enemy slots, player slots, hand, end-turn) within one iPhone viewport where practical. Non-essential boss-roster controls are collapsed below gameplay.

Pirat Kai uses local `public/bosses/level-01-pirat-kai.webp` with a runtime fallback to the canonical Tula asset if the browser cannot decode/load the local file.
